# Промпты для генерации всех иллюстраций упражнений

Этот файл продолжает этап «Промпт 2. Создание первой партии иллюстраций» из `IMPLEMENTATION_PROMPTS.md`. Копируй промпты по порядку, по одному за раз. Каждую следующую партию запускай только после визуальной проверки и утверждения предыдущей.

Партии соответствуют `EXERCISE_ART_DIRECTION.md`: всего 31 упражнение и 103 обязательных кадра. Список первой партии из исходного «Промпта 2» здесь приведён в соответствие с утверждённой группировкой арт-дирекшна.

Ожидаемый результат: 6 упражнений, 18 кадров.

```text

Создай и сохрани reference sheet, который станет эталоном персонажа и стиля для следующих партий. Код приложения пока не меняй.

# 30 Day Workout Challenge

Mobile-first offline workout PWA built with React, TypeScript, Vite, Zustand, Tailwind CSS and Framer Motion.

## Run locally

```bash
npm install
npm run dev
```

## Quality checks

```bash
npm run typecheck
npm run lint
npm run build
npm run preview
```

The production build is written to `dist/`. Its generated service worker precaches the application shell, workout data, illustrations, icons and audio cues.

Product requirements live in `application.md`, architecture decisions in `ARCHITECTURE.md`, and copy-ready staged development prompts in `IMPLEMENTATION_PROMPTS.md`.
